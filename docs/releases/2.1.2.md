# Albion Market 2.1.2

Cette mise à jour améliore les outils de rentabilité des îles :

- Comparaison des cultures à partir de l'historique de marché regroupé.
- Graphiques plus lisibles pour examiner et comparer les profits estimés.
- Ajustements des calculs et du traitement des données de marché associés.

Les estimations dépendent des données disponibles et ne garantissent pas les profits. Les droits de redistribution de certains catalogues restent non confirmés ; voir `docs/data-rights.md`.

## Installation

APK Android de production **2.1.2**, code de version **21**, paquet `com.albion.market`, Android 7.0 ou supérieur, architectures arm64-v8a et x86_64. Signé avec le certificat de production des versions précédentes. Les modèles IA sont téléchargés séparément.

Les fichiers `SHA256SUMS`, `third-party-sources-notices.zip` et `THIRD_PARTY_SHA256SUMS` accompagnent l’APK.

## English summary

Version 2.1.2 improves island crop comparisons using grouped market history and adds more readable profitability charts. Estimates depend on available data. Production-signed Android APK, versionCode 21, Android 7+, arm64-v8a and x86_64.
